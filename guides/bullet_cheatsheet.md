## `changeDynamics()`
```python
import pybullet as p

x = 0
p.changeDynamics(
    bodyUniqueId=x,
    linkIndex=-1,
    mass=x,
    lateralFriction=x,
    spinningFriction=x,
    rollingFriction=x,
    restitution=x,
    linearDamping=x,
    angularDamping=x,
    contactStiffness=x,
    contactDamping=x,
    frictionAnchor=x,
    localInertiaDiagnoal=x,
    ccdSweptSphereRadius=x,
    contactProcessingThreshold=x,
    activationState=x,
    jointDamping=x,
    anisotropicFriction=x,
    maxJointVelocity=x,
    collisionMargin=x,
    jointLowerLimit=x,
    jointUpperLimit=x,
    ointLimitForce=x,
    physicsClientId=x,
)
```
